## 2. 六角形（ハニカム）＝その街の「場所」と、場所ごとの3つのゲーム（実装済み）

**18か所**の六角形を、4・3・4・3・4個の5段に、ハチの巣のように並べる（一番長い段も4個。以前の19か所＝3・4・5・4・3個は、真ん中の段が5個で六角形が小さくなるため、4個までにそろえた）。1つ1つが街の「場所」で、場所ごとに名前・絵文字・すみかの札（町・森・土・川・海）がある。六角形の大きさは、横は画面の幅いっぱい（4個ぶん）、縦に収まらないときは縦に合わせて決める（スマホ幅で半径53px）。六角形が小さいスマホでは、六角形からはみ出さないよう、札を短い言葉（「▶ あなた」「👥 ひと」）にする。

### ゲーム枠は、街の全員で共有する
- 六角形は3つのひし形に分かれていて、1つ1つが「その場所のゲーム1〜3」（**ゲーム枠**）。枠は**街の全員で共有**する（自分専用ではない）
- 1つの枠は、**同時に1人しか遊べない**。誰かが遊び中の枠には、ほかの人は入れない
- 枠が**決着**したら（ゲームが終わったら）、その枠はそのまま残る（もう一回はできない。ゲーム終了の画面のボタンは「📍 平塚市にもどる」）
- 遊び中のまま長く（3時間）動かない枠は「やめた」とみなして、ほかの人が使える（最初からやり直しになる）
- **自分が同時に遊べるのは、1つの街（エリア）につき1つ**。ちがう街なら、平塚と釧路で1つずつ、同時に遊べる。同じ街では、遊び中のゲームがあるあいだ、ほかの枠は始められない（地図の選択画面に「平塚市では、いま◯◯ ゲーム2を あそび中だよ」と案内と「そこへ いく」ボタンが出る）。終わらせるには、ゲームを終えるか「まけました」を押す
- 場所を通さずに（ルームコードで）始めたゲームには、これらの決まりはかからない

### ひし形の色
すみかは**色ではなく、絵文字・名前・札で伝える**。六角形の色は、ゲームのようすを表すためだけに使う。

| ひし形の状態 | 色・表示 |
|---|---|
| まだ（だれも遊んでいない） | 暗い色 |
| **自分があそび中** | **きいろ（ゆっくり点滅）**。六角形に「▶ あなた あそび中」の札 |
| **ほかの人があそび中** | **青みのある灰色（点滅）**。六角形に「👥 ほかの人 あそび中」の札（複数なら人数） |
| 勝ち（そのチームが得点1位） | **勝ったチームの色**（水＝青緑 / 風＝紫 / 土＝オレンジ） |
| AIが勝ち | **赤（ぬりつぶし）** |

- ゲーム選択の画面では、ほかの人が遊び中の枠は「◯◯さんが あそび中」、決着した枠は「水チームが かったよ」「AIが かったよ」と出て、選べない
- **平塚市の画面だけ**、下に「かった かず」（水・風・土・AI それぞれ、いくつの枠に勝ったか）を出す。釧路市には出さない

### 「まけました」
- 陣取りゲームの画面に「🏳 まけました」ボタンを置いた（遊び中のみ）。押すと（画面の中の確認のあと）、得点にかかわらず**AIの勝ち**としてそのゲームを終わらせる（地図では赤）
- 以前の「ゲーム終了」「新規マップで再開」ボタンは外した

### 陣取りゲーム画面のスマホ対応（640px未満）
- **盤面を縦長にする**：30列×15行の盤面を、スマホでは15列×30行に置き直して表示する（データはそのまま。表示だけ縦横を入れかえる）。1マスが約10pxから約23pxになり、タップしやすい。スマホを横向きにしなくても使える
- 盤面のまわりの白い枠（箱）をなくして、画面いっぱいに表示する
- **手札とボタンは、画面の下にまとめて固定する**（1024px未満）：手札は「Lv1 川エビ×1 Lv2 …」と、横にスクロールする1本の帯。ボタンは「↩ キャンセル」「⏭ スキップ」「🏳 まけました」「📍 平塚市」の4つが横一列。盤面を長くスクロールしても、いつでも使える
- チーム名と点数は、スマホでも必ず1行（3チームが横一列。「風 0点 ▶」のように短く表示）。「ルームを変える」ボタンは、全デバイスで外した

### ゲームの読み込みを速くした
- 陣取りゲームを開くときの読み込み（カード一覧・保存データ・チームの所持カード・ユーザー・枠のようす）は、順番に待たず、**同時に始める**。保存の書き込みも待たずに画面を出す（PCで約3秒→約1秒。通信が遅いスマホでは、順番待ちが減る分、差はもっと大きい）

### 場所をタップ → 3つのゲームから選ぶ
- 六角形をタップすると、「ゲーム1・2・3」を選ぶ画面が出る
- 陣取りゲームの画面の上には、ルームコードの代わりに、選んだエリアの名前を「📍 高麗山 ゲーム2」のように表示する（場所の情報が街の名前だけなら「📍 平塚市」）。下のボタンは「📍 平塚市」（その街の六角形の画面にもどる）

### 盤面はすみかの影響を「少しだけ」受ける
- 盤面の地形の割合は、ふつうの盤面の割合に、場所のすみかの割合を**4割だけ混ぜて**決める（`generateSpotBoard`、`SPOT_INFLUENCE = 0.4`）
- 場所とゲーム番号から盤面の元になる数を決めるので、同じ場所の同じゲームは、何度開いても同じ盤面。場所が違えば、ゲーム1〜3も別の盤面
- 地図の場所を通らずに始めたゲームは、これまで通りのランダムな盤面

### 場所のデータ（Firestore `mapSpots`）

- 場所の一覧は Firestore の **`mapSpots/{場所ID}`** に入れている（36件＝平塚18＋釧路18。2026-10-03に登録）
  - 項目：`city`（hiratsuka / kushiro）、`name`、`icon`、`habitat`（town / forest / dirt / river / sea）、`row`（0〜4段目）・`col`（その段の左から何番目か）、`order`
- 地図画面はここから読み込む。**空・読み込み失敗のときは、同梱のデータ（`src/views/DominationGame/mapSpots.json`）を使う**
- 場所を足す・名前を変えるときは、`mapSpots` のドキュメントを直す（同梱のデータも合わせて直しておく）
- 街の名前・中心の位置は `mapSpots.json` の `cities` に書いてある（こちらはFirestoreには入れていない）

### ゲーム枠のデータ
- **`dominationGames/{枠ID}`**：ゲームの盤面そのもの。枠ID＝`{場所ID}-{1〜3}`（例：`hiratsuka-komayama-2`）。遊んでいる人（`ownerUid`・`ownerName`・`ownerTeam`）、`place`、`result` も入る
- **`mapSlots/{枠ID}`**：地図に出す、軽い「枠のようす」。`city`、`spotId`、`gameNo`、`state`（playing / finished）、`ownerUid`、`ownerName`、`ownerTeam`、`winnerTeam`、`humanWon`、`updatedAt`。地図はこれだけを読む（盤面は読まない）。ゲームが動くたび・終わったときに更新する
- 勝ち負け：ゲームが終わると、得点が一番高いチームの勝ち。「まけました」のときはAIの勝ち。`humanWon` が false なら地図で赤、true なら勝ったチームの色で塗る

## 3. すみか別の盤面（試作）と比較ページ

**海・町・森の盤面の比較は `/habitat-compare` で見られる**（モニタールームの仮リンクには出していない。URLを直接開く）。

- 「🎲 つくりなおす」で、盤面を作り直せる
- 盤面は陣取りゲームと同じ大きさ（30×15）・同じ地形（町・森・土・川・海・未開発地）
- 生成のしくみは `src/views/DominationGame/habitatBoard.js`。すみかごとに地形の割合を変え、海は1辺に寄せて海岸のようにする

| すみか | 盤面の特徴（ある1回の例） |
|---|---|
| 🌊 海（例：平塚の海岸） | 海 61% / 町 16% / 森 11% / 未開発地 8% / 土 4%。1辺が海になった海岸の盤面 |
| 🏘 町（例：平塚駅前） | 町 45% / 未開発地 18% / 川 17% / 土 11% / 森 9%。町が大きくかたまり、川が横切る |
| 🌲 森（例：高麗山） | 森 51% / 川 17% / 土 13% / 未開発地 10% / 町 8%。森が広く、川が2本通る |

- ページの下には、そのすみかのカードが何種類あるか（カードDBの数）も出している
- この比較ページは、すみかの影響が強い版（海なら海が6割など）。**ゲーム本体には「影響を少しだけ（4割）」にした版を取り込み済み**（2章）
- 比較ページは試作なので、比較が終わったら削除する（`src/views/HabitatCompare/` と `router/index.js` の `/habitat-compare`）

## 4. これから決めること・作ること

### 場所とカードの結びつけ（未定）
次のどれにするか決める。
1. 盤面の地形とカードのすみかが合うとボーナス点が入る
2. 地域のカードだけが、遊べる手札になる
3. 結びつけない（場所は盤面の見た目だけ変える）

### そのほか
- 場所の一覧（名前・位置）は仮。実際の位置に合わせるか、名前を確定する
- 3つのゲームを全部勝ったときの演出（六角形全体が光る、など）は未実装
- 決着した枠は、いまは再戦できない。全部の枠が決着したあとのこと（リセットの方法、期間ごとの入れ替えなど）は未定
- やめたまま放置された枠の扱い（いまは3時間で解放）は、運用を見て調整する
- 平塚市以外（釧路市）にも、チームごとの勝った数を出すか
