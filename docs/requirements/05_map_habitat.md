## 2. 六角形（ハニカム）＝その街の「場所」と、場所ごとの3つのゲーム（実装済み）

**18か所**の六角形を、4・3・4・3・4個の5段に、ハチの巣のように並べる（一番長い段も4個。以前の19か所＝3・4・5・4・3個は、真ん中の段が5個で六角形が小さくなるため、4個までにそろえた）。1つ1つが街の「場所」で、場所ごとに名前・絵文字・すみかの札（町・森・土・川・海）がある。六角形の大きさは、横は画面の幅いっぱい（4個ぶん）、縦に収まらないときは縦に合わせて決める（スマホ幅で半径53px）。六角形が小さいスマホでは、六角形からはみ出さないよう、札を短い言葉（「▶ あなた」「👥 ひと」）にする。

### ゲーム枠は、街の全員で共有する
- 六角形は3つのひし形に分かれていて、1つ1つが「その場所のゲーム1〜3」（**ゲーム枠**）。枠は**街の全員で共有**する（自分専用ではない）
- 1つの枠は、**同時に1人しか遊べない**。誰かが遊び中の枠には、ほかの人は入れない
- 枠が**決着**したら（ゲームが終わったら）、その枠はそのまま残る（もう一回はできない。ゲーム終了の画面のボタンは「📍 平塚市にもどる」）
- 遊び中のまま長く（3時間）動かない枠は「やめた」とみなして、ほかの人が使える（最初からやり直しになる）
- **自分が同時に遊べるのは、1つの街（エリア）につき1つ**。ちがう街なら、平塚と釧路で1つずつ、同時に遊べる。同じ街では、遊び中のゲームがあるあいだ、ほかの枠は始められない（地図の選択画面に「平塚市では、いま◯◯ ゲーム2を あそび中だよ」と案内と「そこへ いく」ボタンが出る）。終わらせるには、ゲームを終えるか「まけました」を押す
- 場所を通さずに（ルームコードで）始めたゲームには、これらの決まりはかからない

### ひし形の色
すみかは**色ではなく、絵文字・名前・札で伝える**。六角形の色は、ゲームのようすを表すためだけに使う。

| ひし形の状態 | 色・表示 |
|---|---|
| まだ（だれも遊んでいない） | 暗い色 |
| **自分があそび中** | **きいろ（ゆっくり点滅）**。六角形に「▶ あなた あそび中」の札 |
| **ほかの人があそび中** | **青みのある灰色（点滅）**。六角形に「👥 ほかの人 あそび中」の札（複数なら人数） |
| 勝ち（そのチームが得点1位） | **勝ったチームの色**（水＝青緑 / 風＝緑 / 土＝オレンジ） |
| AIが勝ち | **色はつかない（決着にしない）**。ゲームの記録を消して、枠をあける＝ほかの人も、自分も、**再戦できる** |

- ゲーム選択の画面では、ほかの人が遊び中の枠は「◯◯さんが あそび中 👀 観戦できるよ」、決着した枠は「水チームが かったよ 👀 観戦できるよ」と出る。押すと**観戦モード**で入る（下の「観戦モード」）
- **平塚市の画面だけ**、下に「かった かず」（水・風・土、それぞれ、いくつの枠に勝ったか）を出す。釧路市には出さない
- 昔のデータで、AIが勝って終わった枠（`humanWon: false`）は、地図では「あいている枠」として扱う（データは消さない。次に遊ぶときに上書きされる）

### 観戦モード（ほかの人のゲーム・おわったゲーム）
- ゲーム選択で、ほかの人があそび中の枠・決着した枠を押すと、**観戦モード**で入る（`localStorage.dominationSpectate = "1"`）。見るだけ
- 画面の上に、**むらさきの「👀 観戦モード」の帯**（「◯◯さんの ゲームを 見ているよ（見るだけ。さわれないよ）」と「もどる」）。画面のふちもむらさき。カード・スキップ・まけましたは出ない。置かれたカードは、タップで見られる
- あそび中のゲームは、Firestore の変化に合わせて、盤面・点数が**自動で更新**される。ゲームが終わると結果の画面（ごほうび・テラは出ない）。遊んでいた人が「まけました」で枠があいたときは、「ばしょが あいたよ」と出て、地図にもどる
- 観戦では、**保存・テラ・AIの動きは、いっさい起きない**

### AIテストエリア（テストモードだけ）
- 手元の開発環境、または URL に `?test=1` を付けたときだけ、日本地図に「🧪 AIテスト」が出る（日本海）。押すと、平塚・釧路と同じ**六角形（18か所×3ゲーム）**の画面になる（`mapSpots.json` の `cities.aitest`・`aitest-01〜18`。Firestoreには入れていない）
- どの枠も、**何回でも・いつも最初から**遊べる（前の結果が残っていても、ほかの人が遊んでいても関係ない。DBを手でリセットしなくていい）。動画・ABゲームのチュートリアルもない
- 終わると、**勝ったチームの色**がひし形にぬられる（**AIが勝ったときも**、そのAIチームの色。ほかの街とちがい、AIが勝っても枠はあかない＝色を残して、また遊べる）。画面の下に、**チームごとの勝った数と勝率**（例：水 3 (50%)・全6戦）を出す
- テラは入らない。結果は `mapSlots/{枠ID}` に `test: true` つきで入る（ふつうの街の「つづきから」「あそび中」の判定には使わない）
- ヘッダーではなく、「🃏 あなたのカード」のすぐとなりの「🧪 カードを えらぶ」から、全カードを選んで手札に足せる（使ったゲームは、テラが入らない。AIテストは、もともと入らない）
- 最後まで遊ぶと、記録（チームごとの点・レベル別の数）が `gameResults` に残る → 「けっか くらべ」（`/result-compare`。モニタールームの仮リンクから）で見られる。上の**スライド**（ゲームの一覧。ピラミッドの形が見える）からゲームを選ぶと、下の**メイン**に、そのゲームの順位と、**10の見せ方**（つみあげ・三角ピラミッド・ひょうしょうだい・ドーナツ・レーダー・カードのならべ・あわの表・ぼうグラフ・タイル・ねんりん）が出る。「プレイ」のゲームには「🎮 ゲームの画面で 見る」があり、その枠の、いちばん新しいゲームを、観戦モードで開く（盤面や「ふりかえる」も見られる）
- AIテストの、おわった枠は、「👀 おわった けっかを 見る」から、観戦モードで、盤面・じんち・生態系ピラミッドを見られる
- **ふりかえり**：終了画面の「▶ ふりかえる」で、そのゲームを、はじめから**1手ずつ**見なおせる（再生・一時停止・1手もどる／すすむ・スライダー。**1手ごとの間は 0.02（さいそく）／0.05／0.1／0.25／0.5／1／2／3／5秒から選べる**（初期値は1秒。選んだ値は端末に残る）。**ふりかえりは、いつも虫眼鏡（盤面ぜんたい）の表示**で、終わると、始める前の表示にもどる。いまの手は光る。点数も、その時点のものが出る）。置いた手は、ゲームの保存の `moves`（`{t:マス, p:チーム, tier, l:カード名, e:食べたマス}`）に残している。この機能が入る前のゲームには、記録がないので、ふりかえれない

### 「まけました」
- 陣取りゲームの画面に「🏳 まけました」ボタンを置いた（遊び中のみ）。押すと（画面の中の確認のあと）、得点にかかわらず**AIの勝ち**としてそのゲームを終わらせる（AIが勝つと、枠はあいて、ほかの人が再戦できる）
- 以前の「ゲーム終了」「新規マップで再開」ボタンは外した

### モニタールーム（地図とのつながり）
- **地球のモニターの％**：平塚のゲーム（場所18か所×3つのゲーム＝54か所ぶん）のうち、**チームごとに、勝ったゲームの割合**を出す（🌱＝土チーム、💧＝水チーム、🌬＝風チーム）。`mapSlots` から数える（以前は、見せかけの固定の数字だった）。まだ誰も勝っていなければ0%。「平塚の かんりょうりつ」の注釈つき
- **上のモニターは、それぞれ少し色を変える**：チームの色を元に、地球＝青系、洞窟探検＝黄系、野生にもどそう＝緑系を混ぜる（`color-mix`。対応していないブラウザでは、これまで通りチームの色）
- 「◯◯の部屋」のテーブルは、1つだけ

### 陣取りゲーム画面のスマホ対応（640px未満）
- **盤面を縦長にする**：30列×15行の盤面を、スマホでは15列×30行に置き直して表示する（データはそのまま。表示だけ縦横を入れかえる）。1マスが約10pxから約23pxになり、タップしやすい。スマホを横向きにしなくても使える。盤面のまわりの白い枠（箱）もなくして、画面いっぱいに表示する
- **画面全体はスクロールしない**（1024px未満）：上（見出し）と下（カード・ボタン）は固定で、**まん中の盤面の部分だけ**がスクロールする
- **上の部分（見出し・チームの点数）はずっと見える**。盤面とのさかいめは、太い線（3px）とかげではっきりさせる
- **見出しの右はし**に、丸いボタンを2つ置く（上の部分にあるので、盤面をスクロールしても見える）
  - **？**：押すと、地形とレベル（点数）の説明をモーダルで表示する
  - **🔍（虫眼鏡モード）**：盤面ぜんたい（30行ぶん）が、まん中の部分に収まる大きさにする。もう一度押すと、もとの大きさ（マスが大きく、縦にスクロール）にもどる。スマホのみ
- **下のカードとボタン**（1024px未満）：濃い色にして、上に**今の手番のチームの色の線**をひく。そのうえで、**カードとボタンは、色もわくもちがう別のエリア**にする
  - カードエリア：うすい紺色の、枠つきの面。「🃏 あなたのカード」のタイトルつき。カードは**2行**（はみ出す分は横にスクロール）。チップの先頭の小さい数字がレベル。カードを選んだときや、AIの手番のときの案内は、このタイトルの右に出る
  - ボタンエリア：もっと濃い面。高さを使わないよう**1段**で、「⏭ スキップ」「🏳 まけました」「📍 平塚市にもどる」の3つが横一列。以前の「キャンセル」は、カードを選ぶときの確認の画面で取り消せるので、スマホでは外した（広い画面のサイドバーには残している）
- 広い画面（1024px以上）は、右のサイドバーにカードとボタンを出す（下のバーは出さない）
- **標準のダイアログ（`confirm` / `alert`）は使わない**：埋め込みのブラウザやホーム画面アプリでは出ずに処理が止まることがあり、「スキップが効かない」原因になっていた。スキップの確認は画面の中のダイアログ、「このタイルにはおけないよ」などの案内は画面の中のメッセージ（数秒で消える）にした
- チーム名と点数は、スマホでも必ず1行（3チームが横一列。「風 0点 ▶」のように短く表示）。「ルームを変える」ボタンは、全デバイスで外した

### 効果音とAIの点滅（陣取りゲーム）
- 効果音は、ゲーム機のような音ではなく、**水・木・風・鈴のような、静かで自然な音**（禅のような音）にそろえている。ふだんは、Web Audioで作った音（ひびきつき。`src/utils/sfx.js`）
- フリー素材（「Nature Sounds Pack」Antoinemax、CC-BY 4.0＝クレジット必須。[docs/credits.md](../credits.md)）の録音を23こ `public/sounds/pack/` に入れてある（葉ずれ・草の足音・小川・鳥など）。**音くらべの画面（`/sound-test`。モニタールームの仮リンクから）**で、場面ごとに録音を聞きくらべて、えらべる（その端末の `localStorage.sfxSlots` に入り、すぐゲームに反映される）。決まったら、コードの初期値にする
- **効果音**：Web Audio API で、その場で合成した音（音声ファイルは使わない。`src/utils/sfx.js`）。ヘッダー右の「🔊」ボタンでオン・オフ（設定は `localStorage` の `sfxMuted`）。スマホは、画面をタップしたあとでないと音が出ないため、最初のタップで音を使える状態にする

| タイミング | 音 |
|---|---|
| カード・丸いボタンをタップ | 短いピッ |
| 自分がカードを置いた | ポン、ピン（上がる2音） |
| 食べた（カードを置いて、となりを食べたとき） | がぶっ（下がる音を2回） |
| カードを置いた（自分・AI） | **置いた場所の地形で音が変わる**：海＝やさしい波／川＝しずく（ぽとん）／森＝葉ずれ＋木のコッ／町＝木のコトッ／土＝やわらかい土の音（自分のときは、最後に小さな鈴が足される。AIは少し小さい） |
| 自分の番になった | ピンポン |
| スキップ | 低いブッ（下がる音） |
| 置けない・注意メッセージ | ブッ |
| 勝った | ドミソド（上がる） |
| 負けた（まけました・AIの勝ち） | ソミド（下がる） |

- **自分の番が終わってからの、AIの動き**を、うるさすぎない動きで見せる（自分が動くまで）
  - AIが置いた**タイル**は、ゆっくり**ぷくぷく**ふくらみ（約1秒ごと）、角が**キラキラ**（✦）光る。ふちは、置いたAIチームの色
  - AIに**食べられたタイル**は、黒い地に、**もとのカード（もとのチームの色で、うすく）**と、白い**「ひび」**を入れ、ふちは**食べたチームの色**にする（もとの形が読める）
  - AIどうしだけのとき（AIテストなど）は、強調するのは**最新の1手だけ**（積み上げない）
  - 「×」だと、もとが何だったか分からないので、**食べられたカードの見せ方くらべ**（`/eaten-compare`。モニタールームの仮リンクから）を作った。レベル4が生まれた盤面（なければ、食べられたマスが多い所）の7×7を、19の見せ方（×・中ぬき・うすく＋すじ・かじられたあと・バッジ・やじるし・案Cをもっとくらく・赤い斜線・きんしマーク・モノクロ＋かど・はんぶんこ・ひびわれ・シルエット、ひびの仲間：ひび（食べた色）・ふたつに割れる・ガラスわれ・かけた・くだけた・ひび＋くらく）でならべる。**案L（ひびわれ）を採用**し、盤面に入れた
  - 最後のAIの手が画面の外にあるときは、自分の番にもどったときに、そこまで自動でスクロールする
  - 自分がカードを置く・スキップすると、表示は消える
  - 以前の「ずっと点滅」「大きく拡大」「さっきの うごきの一覧」「置いた順番の数字」は、やりすぎ・分かりにくいので、やめた

### 地形のうっすらした模様
地形が分かりやすいよう、空いているマスに、見やすさをじゃましない、うすい模様を付ける（SVGで、マスの大きさに合わせて拡大・縮小）。カードが置かれたマス（黒っぽい色）・食べられたマス・陣地の表示には、付けない。

| 地形 | 模様 |
|---|---|
| 森 | 草の葉 |
| 町 | 小さな家 |
| 土 | つぶつぶ |
| 川 | ゆるい波 |
| 海 | 大きめの波 |
| 未開発地（黒） | ななめの線（「タップして、なおせる」） |

### マスの色（見分けやすさ）
| マス | 見た目 |
|---|---|
| 何も置かれていない | 地形の色（町・森・土・川・海・未開発地） |
| **使われた（カードが置かれた）** | **黒っぽい色**（濃い紺がかった黒）に、置いたチームの色のふちと、チームの色の形（三角・四角・丸・★）。形がくっきり見える |
| **食べられた** | **食べたチームの色に、ななめのしま模様**。形はうすい灰色 |

以前は、使われたマスが地形の色のままで、食べられたマス（食べたチームの色のベタ塗り）や、チームの色（紫など）のマスと見分けにくかった。

### 置けないカード・スキップ・ゲームのおわり（陣取りゲーム）
- **置けないカードは薄く表示**する：いまの盤面で、置ける場所が1つもないカード（レベル×陸/水ごとに判断）は、薄い灰色で表示する。タップして中身を見ることはできる
- **スキップを光らせる**：自分の番で、置けるカードが1枚もないとき、「スキップ」ボタン（青）と「平塚市にもどる」ボタン（緑）が、**キラキラ**（光って、✦がまたたく）光り、カードの見出しに「おけるカードが ないよ → スキップ」と出る。**自動ではスキップしない**（押すのは自分）
- **順位のごほうび：テラ**：地図のゲーム（ゲーム枠）で、自分のチームの順位に応じて、**1位 +10テラ／2位 +5テラ／3位 +2テラ**（3位は少なめ。`RANK_REWARD_TERA`。仮の数）。ce-n.org の `updatePoints` で加算する（ハブサイトの「合計得点」にも反映される。[currency.md](../currency.md) 参照）
  - 順位は、得点がいちばん高い順（同点は同じ順位）。「まけました」は対象外（テラはもらえない）
  - 1ゲームにつき1回だけ（もらった数を `result.rewardTera` に保存し、読み込み直しても、もう一度もらわない）。ルームコードで始めたゲーム（もう一回遊べる）は対象外
  - ゲーム終了の画面に「🎉 2位 +5テラ」のように出る。もらえなかったとき（通信失敗など）は、その旨を出す。まだテラをもらっていないときは、「1位 +10・2位 +5・3位 +2テラ もらえるよ」と案内する
- **じんち（陣地）**：ゲーム終了の画面に、チームごとの「おさえた マスの かず」を出す。数えるのは、カードが置かれたマスと、食べて自分の色にしたマス。**点数には入らない**（生態系がどれだけ広がったかを見るためのもの）。「🗺 じんちを ばんめんで みる」を押すと、盤面が、おさえたマスをチームの色でぬった表示になり（自分のチームは白いふちつき）、ほかのマスはうすくなる。「けっかを みる」で、結果の画面にもどる
- **考え方（教育ゲームとして）**：「食べる」は、点数を増やしたり減らしたりしない。低いレベル（Lv1）のカードは、食べられても、置くことで生態系の土台になり、にぎやかになるので、それでよい。高いレベルのカードのほうが1枚あたりの点数は高いが、置くには、まわりに低いレベルのカードが必要（食物連鎖のピラミッド）

### レベル4（★）の「支配感」
- ★（食べられていないもの）の**まわり8マス**を、そのチームの色で、ゆっくり光らせる（**支配エリア**）。★本人は、ゆっくり**脈うつ**（大きくなったり戻ったり）。★が食べられたら、エリアは消える
- ★が置かれた瞬間に、画面に「**👑 ◯チームの「ヒグマ」があらわれた！ 生態系のいちばん上のいきもの。まわりをしたがえているよ**」と出る（約4秒）。同時に、ふかい鈴の音（`sfx.lord`。音くらべの場面「レベル4が あらわれた」で、録音にかえられる）
- ふりかえりで、★の手に進んだときも、同じおしらせが出る
- ルールは変えていない（なわばり・ボーナス点は、まだ入れていない）

### AIの強さ（ときどきかしこく）
- AIは、**4回に3回（`AI_SMART_RATE = 0.75`）の割合でかしこく、のこりはランダム**に打つ（以前は2回に1回）
  - かしこい手：置けるすべてのカード×場所を調べて、**点数＋食べられる数（自分のカードは食べない）＋「上のレベルを置ける場所を作る点」＋「上のレベルの近くに置く点」**がいちばん高い手を選ぶ（Lv2以上は、ぜんぶの場所を調べる）
  - 「上のレベルを置ける場所を作る点」（`unlockBonus`）：置くと、となりの空きマスのまわりに、同じレベルが2こそろう（＝ひとつ上のレベルが置ける）なら加点。上のレベルほど大きい（Lv1→Lv2:1.5／Lv2→Lv3:3／Lv3→Lv4:7）。上のレベルのカードを持っていて、そのマスに置けるときだけ
  - 「上のレベルの近くに置く点」（`clusterBonus`）：まわり3マスいないに、すでに上のレベルがあるほど加点。上のレベルが、あつまった「やま」ができて、**Lv4に届きやすくなる**
  - 簡易シミュレーション（AIだけ、5ゲーム）：Lv4が出たゲームは、以前は 3/26 だったのが、**4/5**（合計7枚）。Lv3も、1ゲーム 3〜8枚 から 6〜10枚に増えた
  - ランダムな手：置けるカードを1枚、置ける場所を1つ、ランダムに選ぶ（これまでと同じ）
- 強さは、`AI_SMART_RATE` を変えて調整する（0＝ずっとランダム／1＝ずっとかしこい）。簡易シミュレーションでは、ずっとランダムなAIは、点数の高いカードを選ぶだけの人に負けやすかった

### 黒いマスの「かんきょうチャレンジ」（ABゲーム）
- 盤面の**黒いマス（未開発地）をタップ**すると、「かんきょうクイズ」（ABゲーム、**2もん**）に挑戦できる（以前は「環境をなおしてね」と出るだけだった）
- **2もん、ぜんぶ1かいで正解**したら成功。**1回でもまちがえた問題があれば、しっぱい**（まちがえても、その問題は正解するまで進めるが、1回目で当てた数だけを数える）。問題は、ABゲームの問題（`abGameQuestions`、平塚）から、ランダムに2つ選ぶ
- **成功**：黒いマスが、**となりあうマス（8マス）の、適当な1つと同じ地形**になおり（どの地形になるかは、チャレンジを始めるときに決まる）、**ゲーム内の点数が +3**（`AB_CHALLENGE_POINTS`。仮の数）。自分の番はそのままつづくが、**その番は、なおしたマスにカードを置けない**（つぎの自分の番から置ける。「このマスは、いま なおしたばかり」と出る）
- **しっぱい**：自分の番が、つぎのチームにうつる（何回でもためせてしまわないように）。マスは黒いまま
- **カードを持っていなくても、ちょうせんできる**（以前は「なおる地形に合う Lv1 のカードが必要」だったが、なくした。カードが置けない番でも、点数を稼ぐ手段になる）
- チャレンジのとちゅうで「✕」で閉じると、しっぱい扱い（はじめる前なら、何も起きない）
- **地図の地域チュートリアル（動画のあと）の、ABゲームは外した**：動画が終わると、そのまま地図が開く。ABゲームの画面（`ABGameProposalB`）は、このチャレンジで使う（`embedded` ＋ `challenge` ＋ `questionCount`）

### 置いたカードの形と、あそびかたの説明
- **置いたカードの形**（Lv1＝三角、Lv2＝四角、Lv3＝丸、Lv4＝★）は、SVGで作って、**マスの大きさの約78%**に合わせて拡大・縮小する。黒縁は、拡大・縮小しても**同じ太さ（2px）**で付く。食べられたカードは、うすい灰色
  - 以前は、固定の大きさ（約20px）の形だったため、スマホや虫眼鏡でマスの大きさが変わると、はみ出したり、黒縁が付かなかったりした
- **「？」の説明画面**：「あそびかた」に続いて、盤面と同じ見た目の表が出る。**ちけい**は、盤面と同じ色・もようの見本つき（町・森・土は「りくの いきもの」、川・海は「みずの いきもの」、黒いマスは「タップで クイズ→なおす」）。**レベルと ポイント**は、盤面と同じ形（▲■●★）で、点数（1・3・5・10点）と、おける場所のルール（Lv1はどこでも／Lv2以上はまわりにひとつ下のレベルが2こ）つき。あそびかたは、次の7つ
- **「？」の説明画面に「あそびかた」を追加**（やさしい言葉）：①ナンバー1をめざす ②じゅんばんに1まいずつ ③おける場所（りくは町・森・土、みずは川・海、未開発地はだめ） ④レベルのルール（Lv1はどこでも／Lv2以上は、まわりのひとつ下のレベルが2こ以上。まわりは、たて・よこ・ななめの8マス） ⑤食べる（高いレベルを置くと、まわりの低いレベルを食べる） ⑥ポイント ⑦おわり（カードがなくなる・全員スキップ・まけました）。そのあとに、地形とレベル（点数）の表が続く

### カードの表示は、共通のカード（カードライブラリと同じ）
- 盤面のタイルをタップしたとき（置かれているカード）と、カードのカードをタップしたときの大きなカード表示は、**カードライブラリ・宝箱と同じ共通のカード**（`CollectionCard`）を使う（`GameCardFocus.vue`）
- カードの下に、ゲームのルールに関わる「レベル」と「食べもの」を文字で出す（旧表示の食べもののアイコンは、アイコン用の部品が読み込まれておらず表示されていなかった）
- カードのカードをタップしたときは、「選択する」ボタンつき。タイルをタップしたときは、見るだけ
- カードの発見者は、AIのカードなら「AI」、自分のカードなら自分の名前。カードライブラリにないカード（古い保存のもの）は、旧表示にもどる

### ゲームの読み込みを速くした
- 陣取りゲームを開くときの読み込み（カード一覧・保存データ・チームの所持カード・ユーザー・枠のようす）は、順番に待たず、**同時に始める**。保存の書き込みも待たずに画面を出す（PCで約3秒→約1秒。通信が遅いスマホでは、順番待ちが減る分、差はもっと大きい）

### 場所をタップ → 3つのゲームから選ぶ

### 盤面は、場所のすみかの影響を受ける
- 盤面の地形の割合は、ふつうの盤面の割合に、場所のすみかの割合を**6.5割**混ぜて決める（`generateSpotBoard`、`SPOT_INFLUENCE = 0.65`）。目安（地形の割合の平均）：**海の場所＝海が約38%**／**町の場所＝町が約42%**／**森の場所＝森が約45%**／**土の場所＝土が約31%**。ほかの地形も残る。以前は0.4（海の場所で海が約29%）だったが、場所の違いが分かりにくいので、強くした
- 場所とゲーム番号から盤面の元になる数を決めるので、同じ場所の同じゲームは、何度開いても同じ盤面。場所が違えば、ゲーム1〜3も別の盤面
- 地図の場所を通らずに始めたゲームは、これまで通りのランダムな盤面

### 場所のデータ（Firestore `mapSpots`）

- 場所の一覧は Firestore の **`mapSpots/{場所ID}`** に入れている（36件＝平塚18＋釧路18。2026-10-03に登録）
  - 項目：`city`（hiratsuka / kushiro）、`name`、`icon`、`habitat`（town / forest / dirt / river / sea）、`row`（0〜4段目）・`col`（その段の左から何番目か）、`order`
- 地図画面はここから読み込む。**空・読み込み失敗のときは、同梱のデータ（`src/views/DominationGame/mapSpots.json`）を使う**

### ゲーム枠のデータ
- **`dominationGames/{枠ID}`**：ゲームの盤面そのもの。枠ID＝`{場所ID}-{1〜3}`（例：`hiratsuka-komayama-2`）。遊んでいる人（`ownerUid`・`ownerName`・`ownerTeam`）、`place`、`result` も入る
- **`mapSlots/{枠ID}`**：地図に出す、軽い「枠のようす」。`city`、`spotId`、`gameNo`、`state`（playing / finished）、`ownerUid`、`ownerName`、`ownerTeam`、`winnerTeam`、`humanWon`、`updatedAt`。地図はこれだけを読む（盤面は読まない）。ゲームが動くたび・終わったときに更新する
- 勝ち負け：ゲームが終わると、得点が一番高いチームの勝ち。「まけました」のときはAIの勝ち。**人間が勝ったときだけ**、勝ったチームの色で塗る。AIが勝ったときは、`dominationGames/{枠ID}` と `mapSlots/{枠ID}` を**削除**して、枠をあける（`DominationGame.vue` の `releaseSlot`）
