- 作成日: 2026-10-03
- 目的: このアプリの通貨「テラ」が何で、いまどこまでできていて、これから何を決めるかをまとめる

---

## 1. テラとは

- プレイヤー1人ごとに持っている通貨（ポイント）。名前は「**テラ**」
- 画面では **「0テラ（アイコン）」** の形で、モニタールームの右上のパネルに自分の分を表示する
- **ハブサイト（shineki-game）の「合計得点」と同じもの。** ce-n.org（Wix）側に保存されている `totalPoints` を使う
- **Firestoreにはテラを持たない**（以前あった `users/{uid}.coins` は使わない。新規登録でも作らない）

## 2. 取得と更新の方法（ce-n.org のAPI）

ハブサイトとこのアプリは、同じ ce-n.org の API を使う。コードは `src/utils/points.js` に1か所にまとめてある。

| 操作 | API | 返事 | 使う関数 |
|---|---|---|---|
| **取得**（読むだけ） | `GET https://www.ce-n.org/_functions/findMe?id={cenId}` | 会員情報のJSON。**`totalPoints`** が合計ポイント（`text4` が名前、`hasPointsReached` が「100点到達」）。存在しないIDのときは `{"message": "..."}` | `fetchTotalPoints(cenId)` |
| **更新**（加算） | `GET https://www.ce-n.org/_functions/updatePoints?id={cenId}&increment={加算する点数}` | 配列。`[0].totalPoints` が更新後の合計 | `addPoints(cenId, increment)` |

注意:

- **`updatePoints` はGETなのに、ce-n.org側のポイントが実際に書き換わる。** ハブも同じAPIで加算しているので、ここで足した分はハブの「合計得点」にも反映される。動作確認で気軽に呼ばない（テストユーザーの点数が本当に増える）
- 取得の `findMe` は、ログイン時（`LoginPage.vue`）にも会員確認のために呼んでいる。読むだけなので何度呼んでもデータは変わらない
- ハブ側の処理：開いたときに `findMe` で `totalPoints` を読んで「合計得点」に表示し、ゲームで点が入るたびに `updatePoints` で加算して、返ってきた `totalPoints` を表示し直している
- ce-n.org側（Wix）の設定・データは、このアプリからは変更しない（読むのと、上記の加算APIを呼ぶだけ）
