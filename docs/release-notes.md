## 【地図（野生にもどそう！）】
- 日本全体を、**九州〜北海道がちょうど入る大きさ**で表示。**遊べる地域（神奈川・北海道）だけ緑に光る**（外部の13MBのデータをやめ、約120KBの自前データに）
- 街（平塚市）をタップすると、**なめらかに拡大**（2.5秒）。「◀ もどる」で日本全体にもどる
- **釧路市は「じゅんびちゅう」**（まだ遊べない）
- 街の中に、**18か所の六角形**（4・3・4・3・4個）。場所ごとに名前・絵文字・すみか（町・森・土・川・海）
- 1つの場所に、**3つのゲーム枠**（六角形が3つのひし形に分かれる）。枠は街の全員で共有（同時に1人まで）。同時に遊べるのは、**1つの街につき1つ**
- ひし形の色：自分があそび中＝きいろ（点滅）／ほかの人があそび中＝灰色（点滅）／勝ち＝勝ったチームの色／AIが勝ち＝赤。平塚市の画面に、チームごとの「かった かず」
- 地域チュートリアル：動画のあとの **ABゲームは外した**（動画が終わると、そのまま地図）

## 【陣取りゲーム】
**スマホ**
- 盤面を**縦長**（15列×30行）にして、マスを約2倍に。枠をなくして画面いっぱいに
- **画面全体はスクロールしない**：上（見出し）と下（カード・ボタン）は固定で、盤面だけスクロール
- ヘッダー右に、**？**（あそびかた・地形・レベルの説明）と **🔍**（盤面ぜんたいを1画面に）と **🔊**（効果音のオン・オフ）
- 下のバー：カードは2行（横スクロール）、ボタンは1段（スキップ／まけました／平塚市にもどる）。カードとボタンは、色もわくも別のエリア
- チーム名と点数は1行。ルームの札は、選んだ**エリア名**（📍 高麗山 ゲーム2）。「ルームを変える」「ゲーム終了」「新規マップで再開」は削除

**見た目**
- **カードの大きな表示**は、カードライブラリと同じ共通のカード（レベル・食べものつき）
- 地形に、うっすらした模様（森＝草、町＝家、土＝つぶ、川・海＝波、黒いマス＝ななめ線）
- 使われたマス＝黒っぽい色にチームの色のふち。置いたカードの形（▲■●★）は、**黒縁つきで、マスの大きさに合わせて拡大・縮小**。食べられたマス＝食べたチームの色のしま模様
- 置けないカードは薄く表示

**動き・ルール**
- AIが置いたタイルが、「ぷくぷく」＋「キラキラ」。食べられたタイルは点線。自分の番に戻ったとき、最後のAIの手が画面の外ならスクロール
- **効果音**（カード選択・配置・食べる・AI・自分の番・スキップ・注意・勝ち・負け）
- **置けるカードがないとき**、「スキップ」と「もどる」ボタンがキラキラ（自動ではスキップしない）
- 「**まけました**」ボタン（AIの勝ち扱い）。スキップの確認は、画面の中のダイアログに（標準の `confirm` は、環境によって出ずに止まっていた）
- **1位 +10／2位 +5／3位 +2テラ**（地図のゲームのみ。1ゲームにつき1回）
- ゲーム終了の画面に、順位・テラ・**じんち**（チームごとの、おさえたマスの数）。「じんちを ばんめんで みる」で、盤面でも見られる（点数には入らない）
- **AIが半分の割合でかしこく**（点数の高いカード・相手を食べられる場所）。残りはランダム
- **黒いマスの「かんきょうチャレンジ」**：黒いマスをタップ → ABゲーム2問。ぜんぶ1回で正解なら、**+3点**で、マスが**となりのマスと同じ地形**に（その番は、なおしたマスに置けない）。しっぱいは、番が次にうつる。カードがなくても挑戦できる
- 場所のすみかが、盤面の地形の割合に反映される（海の場所で海が約4割、森の場所で森が約4〜5割。同じ場所・同じゲームは、同じ盤面）
- 開くときの読み込みを、同時に進めて**速く**（約3秒→約1秒）

## 【端末の集計（`/device-stats`）】（新規・管理者用の仮画面）
- どんな端末で使われているかを、**個人を特定しない、粗い分類だけ**（端末の種類・画面の幅の区分・OSの名前・ホーム画面アプリか）、**1つの端末につき1日1回、回数だけ**数える。外部の解析サービスには送らない
