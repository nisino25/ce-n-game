# 外部サービスのコスト整理

- 作成日: 2026-09-26
- 目的: このアプリが依存している外部サービスについて、「いつ・どうなったら課金が発生するか」と「コストカットのために出来ること」を整理する
- 注意: FirebaseとNetlifyは実際にログインして数値を確認済み（2026-09-26時点）。ce-n.org（Wix）側はこのアプリの管轄外のため未確認（4章参照）

---

## 1. Firebase（Firestore） — 確認済み・現状無料

- プロジェクトID: `ce-n-game`（[src/firebase.js](../src/firebase.js)）
- **プラン: Spark（無料プラン）。現在の請求額: No-cost（0円）**（2026-09-26、Firebaseコンソール「Usage and billing」で確認）
- Blazeプラン（従量課金）へのアップグレードは行われていない。**Sparkのままである限り、そもそも課金は発生しない**（上限を超えると課金ではなく機能制限・エラーになる仕様）

### 2026-09-26時点の使用量（当月・Cloud Firestore）

| 項目 | 使用量 | 無料枠上限 | 使用率 |
|---|---|---|---|
| 書き込み（Writes） | 92 | 20,000 / 日 | 0.5% |
| 読み取り（Reads） | 1,700 | 50,000 / 日 | 3.5% |
| 削除（Deletes） | 20 | 20,000 / 日 | 0.1% |

- 追加で課金対象になりうる項目: **保存データ量が1GBを超えた分**、**帯域幅が月10GBを超えた分**（Sparkプランのまま、かつBlazeにアップグレードしていない場合はこれらも課金ではなく制限扱い）
- **課金が発生する唯一のトリガーは「誰かが意図的にBlazeプランへアップグレードする」こと**。それさえしなければ現状の使用量（数%程度）が10倍以上に増えても無料のまま

## 2. Netlify — 確認済み・現状無料

- チーム: `nisino25`（GitHub連携ログインで確認）
- **プラン: Free。支払い方法の登録なし。請求額 $0.00**（2026-09-26、Usage & billing画面で確認）
- **課金が発生する唯一のトリガーは「有料プランへ手動アップグレードする」こと**。Freeプランの上限を超えても、支払い情報が未登録のため自動課金はされず、機能制限がかかる形

### 2026-09-26時点の使用量（当月）

| 項目 | 使用量 | 無料枠上限 |
|---|---|---|
| 帯域幅（Bandwidth） | 0 KB | 100 GB / 月 |
| ビルド時間 | 10分 | 300分 / 月 |
| 同時ビルド数 | 0 | 1 |
| プロジェクト数 | 76 | 500 |

- 月間の実績としても、Web リクエスト数は7月10K・8月5.5K・9月7.2K程度、ビルド時間は8月6分・9月11分程度と、上限に対してごく僅か
- **現状、Netlifyの利用状況では課金の心配はほぼ無い**（今回追加した重い画像ファイルを踏まえても、100GB/月の帯域上限に対して余裕がかなりある）

## 3. ikimono-api（生き物判定API・Cloud Run） — 現状非公開だが注意ポイント

- 現在MonitorRoomからの導線はコメントアウト済み（[03_creature_scan.md](requirements/03_creature_scan.md)参照）で、一般来場者は呼び出せない状態
- Cloud Run自体は待機時ゼロスケールで基本無料だが、**リクエストのたびに一定の処理時間・呼び出し回数に応じた課金が発生する**（連携ガイドPDFより。少額だが「リクエストするたびに発生」する点は他と違う）
- 開発中の動作確認（curl/fetch）でも実際に課金が発生した実績あり（数円程度）
- **要確認**: Cloud Runコンソールで予算アラート・インスタンス数上限が想定通り設定されているか

## 4. ce-n.org（Wix・会員DB） — 未確認・このアプリの管轄外

- 子ども環境ネットワークが運営するWixサイト側のシステムで、このリポジトリの外にある
- このアプリからは`findMe`というVelo（Wixのカスタムバックエンド）APIを`fetch`で呼んでいるだけ（[LoginPage.vue](../src/views/LoginPage/LoginPage.vue)）
- Wixの契約プラン・費用体系はce-n.org管理者側の話であり、このアプリ側からは確認も制御もできない

## 参考: 各サービスの課金トリガーまとめ

| サービス | 課金が発生する条件 |
|---|---|
| Firebase (Spark) | 発生しない。Blazeへ手動アップグレードした場合のみ、無料枠超過分が課金対象になる |
| Netlify (Free、確認済み) | 支払い方法未登録のため自動課金はされない。有料プランへ手動アップグレードした場合のみ課金対象になる |
| ikimono-api (Cloud Run) | **リクエストごとに小額課金**。呼び出し自体が課金トリガーになる点が他と異なる |
| ce-n.org (Wix) | このアプリの管轄外。ce-n.org側の契約に依存 |
